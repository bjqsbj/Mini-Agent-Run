# Mini Agent Run · 智能体代码排查台

默认入口「Agent 故障诊断」接收用户反馈或公开 GitHub Issue，结合上传的 JS/TS 源码调查故障。Doctor 查询状态、日志、配置与执行轨迹，跨轮核对源码，给出关键故障步骤、可点击的证据、修复方案及验收标准。内置八个可单独上传、单独运行的 Agent 故障文件。[八例操作与验收手册](docs/Doctor诊断与八例验收.md)

## 三分钟启动

1. 安装 **Node.js 22.18 或以上版本**，在终端用 `node -v` 核对。[Node.js 下载](https://nodejs.org/en/download)
2. 将 ZIP 完整解压到可写目录，打开含有 `package.json` 的项目文件夹。Windows 双击 **start.cmd**。也可以在此目录运行 `npm.cmd start`，macOS / Linux 运行 `npm start`。
3. 保持终端开着，打开 [本机排查台](http://127.0.0.1:4318)。网页、TypeScript 转译器与 QuickJS 测评器都已打包，体验示例无需安装 npm 依赖。
4. 在「全部诊断案例」选择 **CASE-004 · 流式工具参数缺失**，使用「离线证据回放」，点击「开始诊断」。在报告中点击证据编号，检查模型返回的五个分片、派发时刻及工具实际收到的参数。选中其他案例会同步替换问题，也可以自行上传单文件。
5. 想体验自动改码时，切换「代码修复与回滚」，选「并行工具逆序返回时串线」并开始排查。查看基线 2/3、候选 3/3 的行为测评，再在「源码版本」下载或回滚。

## 使用真实模型和自己的代码

在项目根目录执行以下命令，打开或新建 `.env`，填写一行 `DEEPSEEK_API_KEY=你的密钥`。已有配置时只需确认所用模型与凭证。保存并重启服务、刷新网页。

```powershell
notepad .env
```

选择 DeepSeek 引擎，从「选择代码文件」或「选择源码目录」导入模块，填写复现条件、观测与预期。真实模式会把问题、源码预览或相关源码及查询到的观测发送到 DeepSeek。密钥仅由服务端读取。Doctor 的离线模式按观测选择工具并形成报告。代码修复入口的离线模式会额外执行清单里的候选补丁与行为测评。

**适用范围**为 JS/TS 的 ES 模块和本地相对导入。可选择 pi 风格的工具调度、结果匹配等模块，支持最多 32 个文件、合计 80 KiB。自动行为测评面向同步导出函数，入参及返回值须能用 JSON 表示。依赖终端、网络、文件系统或安装包的整套 Agent，需要提取可独立测量的函数，完整应用集成仍需在原项目运行。

## 开发与验证

从项目根目录执行。只运行应用和测试时无需安装依赖。修改网页或测评器后需重新构建。

```powershell
npm.cmd ci
npm.cmd run check
npm.cmd run build
npm.cmd test
git log --oneline
```

`server/` 是 TypeScript 服务端，`web/src/` 是 Vue 3 页面，`engine/` 是测评器源码，`runtime/` 与 `dist/` 是交付用构建产物。服务默认使用 4318 端口，`data/` 保存本机数据。修改 PORT 或 RUN_DATA_DIR 后需重启。桌面项目保留 Git 提交历史。完整项目压缩包内的 `版本历史.bundle` 可用 `git clone 版本历史.bundle doctor-history` 展开。便携包包含依赖锁文件，运行时从本机单独读取凭证。

## Vibe Coding 复盘

1. 这次使用 Codex 在原版 Git 历史上扩展，保留了事件流、长日志、任务控制与历史回放。
2. 先定义“反馈能否排查”“问题能否复现”“候选能否发布”三个可分开判定的结果。
3. 用一个真实工程中常见的逆序完成问题设计双文件案例，保留顺序完成和空队列两个对照。
4. 将业务证据、预置补丁与函数断言放入 JSON，网页和测试均从同一清单读取。
5. 明确区分规则命中、真实语义判定和离线复现，使模型调用是否发生可从事件回看。
6. 先执行原始代码，再锁定断言评测候选。等值边界的反例说明总通过数可能掩盖回归。
7. 为候选引入精确上下文匹配，用活动版本检查和 SQLite 事务避免旧任务覆盖新快照。
8. 联调发现 Vue 内联双语句经过格式化会导致生产构建解析失败，改为命名事件处理函数。
9. 核对重试时的断言来源，补上模型拟定断言的持久化，使后续比较可复现。
10. 用真实 DeepSeek 跑通内置网关场景，核对筛选、工具调用、代码生成和版本入库。
11. 自动测试还覆盖停止、断流、重启恢复、错误补丁、过期版本写入和隔离测评超时。
12. 最后从浏览器上传双文件模块、导入 JSON、下载修复 ZIP 并回滚，再核对交付包。
